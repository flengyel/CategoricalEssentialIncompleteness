# Logical consequence and essential incompleteness in recursion categories

Gödel’s arithmetization represents formulas and finite proofs by numbers and
their effective operations and relations within arithmetic. We begin with
computation, axiomatized by recursion categories, and construct internal
propositional and first-order deductive systems. The construction takes
place in a regular, extensive category of total morphisms of a
restriction idempotent completion. Monomorphisms must have partial inverses
in the completion, and syntax and initial algebras for finite derivations
must exist with parameters in every slice. A total reduction of an inseparable pair to
the theorem and refutation subobjects of a consistent theory makes every
consistent internal extension incomplete. Generation is left adjoint to inclusion of
deductively closed theories, and logical translations induce Galois
connections. Theory inclusions induce fully faithful functors between
associated Turing categories. A consistent theory containing a fixed global logical theorem is
essentially incomplete if and only if its constant family in the
associated category is essentially incomplete. These
constructions give a formulation of the generalized incompleteness sought
by Di Paola and Heller. In the completion of the syntactic recursion
category for Peano arithmetic, we represent computably enumerable
extensions of Peano arithmetic by internal theories. For each consistent
extension, a categorical comparison theorem proves incompleteness of both
the internal theory and the arithmetic extension. A uniform construction
gives an independent sentence from an index for the extension’s axiom
enumeration. A realization based on a Miller sequence gives a consistent
theory of real closed fields expanded by constants naming the sequence.
Every consistent extension is incomplete if one oracle program
semidecides its axioms using every binary representation of the sequence.
A realization using cosheaves on a three-point space gives two consistent
propositional theories whose consistent extensions in the same language
with computably enumerable axiom sets are incomplete. These theories have
conservative first-order extensions. The construction of associated
categories applies to a first-order theory generated by the arithmetic
diagonal pair, the Miller field theory, and the first-order extension of
the internal cosheaf theory.

## Clone or use the existing checkout

For a new checkout, use GitHub SSH authentication:

```bash
git clone git@github.com:flengyel/CategoricalEssentialIncompleteness.git
cd CategoricalEssentialIncompleteness
```

For an existing checkout, inspect `git status --short --branch` and
`git remote -v` before updating. Preserve local changes and use the existing
repository. Run the commands below in Debian or another Linux environment,
including WSL2.

## Build and verify Lean

Git, Python 3.9 or later, and Elan are required. The Lake project is in `Lean/`.
Its toolchain and complete dependency manifest are pinned; do not change
Elan's global default or copy another project's compiled files.

| Component | Pin |
| --- | --- |
| Lean | `leanprover/lean4:v4.35.0-rc2` |
| Mathlib | `065356127b1dc0016f66b7283ce0ce2c4055aa55` |
| Foundation | `01f617fbe240a84aaf1c45b31b9d65e0a2e21c1d` |

For an already prepared checkout, run from the repository root:

```bash
bash scripts/verify-wsl.sh
```

For initial setup, `bash scripts/setup-wsl.sh` installs the pinned toolchain,
obtains its Mathlib cache, and invokes verification once. The verification
wrapper takes a project build lock, sets `LEAN_NUM_THREADS=1`, and preserves
the starting commit, Git status, exit status, logs and machine-readable result
in a fresh ignored `.codex-work/verify-*` directory. The underlying verifier
remains `python3 scripts/verify.py` and writes to `build-logs/`.
Run one heavy verification process at a time across projects. WSL2 does not need the hosted
executable-path adapter described in [HOST_BUILD.md](HOST_BUILD.md).

## Build the manuscript

With `latexmk` and the required TeX packages installed, run from the repository
root:

```bash
cd manuscript/latex
latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex
```

This produces `manuscript/latex/main.pdf`. The versioned publication PDF remains
in `manuscript/`. The [LaTeX guide](manuscript/latex/README.md) lists the source
