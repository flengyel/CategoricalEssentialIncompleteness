## Proposed manuscript lemma

The following makes the computational data and quantifiers explicit. Its finite-trace argument is an elaboration of the cited formalization, not a claim that Montagna prints these four identities verbatim.

```latex
We use the arithmetization of deterministic computations underlying
Montagna's construction \cite[pp.~108, 115, Note~1]{Montagna}.
Write $\mathsf T(e,x,t)$ for the formula saying that $t$ codes a
halting computation of program $e$ on input $x$, and
$\mathsf U(t,y)$ for the formula saying that its output is $y$.
Put
\[
 G(e,x,y):=\exists t\,
   \bigl(\mathsf T(e,x,t)\land\mathsf U(t,y)\bigr).
\]
These formulas are chosen so that $G$ is $\Sigma_1$.
Primitive-recursive functions in arithmetic formulas are written as
abbreviations in a conservative definitional extension of $\PA$.

\begin{lemma}\label{lem:formal-computation}
The computation coding can be chosen with a universal program index
$u$ and primitive-recursive functions
$s,\operatorname{comp}:\N^2\to\N$ for which $\PA$ proves the
universal closures of
\begin{align*}
 G(e,x,y)\land G(e,x,z)&\longrightarrow y=z,\\
 G(u,\langle e,x\rangle,y)&\longleftrightarrow G(e,x,y),\\
 G(s(e,a),x,y)&\longleftrightarrow
                         G(e,\langle a,x\rangle,y),\\
 G(\operatorname{comp}(f,e),x,z)&\longleftrightarrow
             \exists y\,(G(e,x,y)\land G(f,y,z)).
\end{align*}
The functions $s$ and $\operatorname{comp}$ have programs whose
totality and defining equations are provable in $\PA$.
\end{lemma}
```

The pair coding in this display must be the one fixed for the formal numerical product, or the manuscript must give its PA-provable comparison with that coding. It is not a new pairing convention to be silently substituted for the earlier one.

## Finite-trace proof of the lemma

This is a proof of existence of the chosen data. It does not presume that an arbitrary acceptable numbering has the required PA-provable properties.

Choose a conventional deterministic register-machine presentation, with finite programs and finite configurations encoded by primitive-recursive sequence operations. Instructions may be zeroing, increment, copy, conditional equality jump, and halt; malformed program codes run a fixed loop. The next-configuration operation is primitive recursive and deterministic. Halting configurations are absorbing. A computation code is a finite sequence beginning at the specified input configuration, satisfying the transition relation at successive entries, and ending at a halt. Its last register value is the output. The associated trace/output formulas can be taken in the usual Kleene normal form described in Montagna's Note 1; existential quantification over the trace gives a Sigma_1 output formula in the language of PA.

The proof of functionality is induction on the shorter of two computation lengths. Determinism makes the corresponding configurations agree until one computation halts. The absorbing halt convention forces both outputs to agree. This induction is formalizable in PA uniformly in the program code, input, and two trace codes.

Let `u` be the program which decodes its input as `(e,x)`, builds the initial configuration of program `e`, and repeatedly computes its next configuration until it reaches a halt, when it returns the simulated output. A halting source trace is converted into a halting interpreter trace by expanding each simulated transition into the fixed interpreter code. Conversely, a halting interpreter trace contains a sequence of simulated configurations at the interpreter's loop boundaries; extracting these gives the source trace. Both constructions are primitive recursive on finite trace codes. PA proves their correctness by induction on the number of transitions. This proves both implications of the universal-program graph identity; it does not assert that the interpreter always halts.

The program with index `s(e,a)` first constructs the pair `(a,x)` from its input `x` and the inserted numeral `a`, and then invokes the interpreter on program `e` and that pair. The code is obtained by inserting the two constants into a fixed program template and shifting the finitely many instruction addresses. This is primitive recursive in `(e,a)`. Insertion and deletion of the deterministic initialization block, followed by the preceding interpreter-trace transformations, prove both implications of the specialization identity in PA.

The program with index `comp(f,e)` runs the interpreter for `e` on its input, stores the returned value, and then runs the interpreter for `f` on that value. Its code is again produced by a primitive-recursive template operation. A halting composite trace determines the intermediate value and the two subtraces. Conversely, the two halting traces concatenate with the fixed transition between the two calls. PA proves these finite-trace transformations correct, which gives the composition identity. Primitive-recursive compiler functions are represented by the corresponding structurally compiled programs; induction on their primitive-recursive definitions proves their totality and defining equations in PA.

This proof can be compressed in the manuscript to the following paragraph after the lemma, using the exact primary citation above:

```latex
\begin{proof}
Use finite traces of a deterministic machine with a primitive-recursive
transition function. Determinism proves functionality by induction on
trace length. The universal program simulates that transition function;
expanding a simulated trace and extracting the simulated configurations
from an interpreter trace prove its graph identity in $\PA$.
For specialization, insert $e$ and $a$ into the fixed program that forms
$\langle a,x\rangle$ and then runs the interpreter. For composition,
run $e$ and pass its output to $f$. These insertions are
primitive recursive on program codes. Insertion, extraction, and
concatenation of the corresponding finite trace blocks prove both
directions of the displayed identities in $\PA$. The compiler functions
are primitive recursive, so their defining programs are provably total
in $\PA$. This is the formalized parameterization used in
\cite[p.~108]{Montagna}.
\end{proof}
```

## Exact categorical consequence

Let `b_X` be the fixed numerical coding of a formal type `X`, with its PA-provable inverse. Suppose a typed arrow `f:X times omega -> omega` has program index `e`, with encoded input pair `(b_X(x),n)`. Define the parameter program numerically by

`r_e(x) = s(e,b_X(x))`.

Its totality is provable in PA because `b_X` and `s` are primitive recursive. The specialization identity, followed by the universal-program identity, proves in PA the **uniform graph equality** between `f` and `tau (r_e times 1_omega)`. Taking the quotient by uniform T-provable graph equality, for any `T` containing PA, gives the required Turing-morphism equation. Thus the total parameter arrow is constructed and its totality is proved before invoking the categorical universal property.

The fixed program index `e` is an external natural number. The parameter `a=b_X(x)` varies internally; the displayed identities are universally quantified PA theorems, so the construction works in nonstandard models as required by the later interpretation functors.

## Scope and cautions for the combined revision

- The supplied primary papers explicitly justify universal computation and formalized parameterization. They do not justify replacing their computation coding by an arbitrary extensional acceptable numbering and assuming all identities remain PA-provable.
- The graph `G` is Sigma_1, not primitive recursive in general. The finite-trace predicate is primitive recursive. These are different relations and should have different names.
- The displayed compiler symbols denote primitive-recursive numerical functions. Their use inside arithmetic formulas requires the stated definitional-extension convention or explicit graph formulas.
- Only the unprimed construction and its computational ingredients are being cited here. Nothing in this note relies on the claimed categorical properties of the primed systems.
- Exact references to Feferman Theorem 2.13 above are reported through Montagna's explicit application; Feferman's original theorem was not independently retrieved in this task. No new bibliography item is needed to cite Montagna's proved displayed assertion (*).
