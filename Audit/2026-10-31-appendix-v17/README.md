# Boolean operations and conditionals, version 17

Version 17 uses bold truth injections throughout the pullback notation and defines a conditional by an explicitly typed copairing. The standalone Appendix A is Appendix B in the assembled manuscript.

The Boolean operations are computed by composing their defining copairings with each coproduct injection. The four resulting pairs of composites are displayed. The Boolean identities are checked on the jointly epimorphic injections of the relevant finite products, with explicit summand cases for associativity and both distributive laws. The case distinctions concern labelled summands, so the proof also covers a degenerate category.

For a predicate `p:X→2`, the two pullback inclusions define an isomorphism `δ_p=[i_t,i_f]` from their coproduct to `X`. The conditional with branches `f,g:X→Y` is `[f i_t,g i_f]δ_p⁻¹`. Its two restriction equations state the universal property. All existing conditionals use the first branch on the true summand and the second on the false summand.

A separate agent checked these types, the branch order at each use, the bold truth constants in later pullbacks, and the expanded Boolean calculation. Its suggestion to distinguish labelled summands from equality of the truth morphisms was incorporated. This is a targeted review; the [version 14 reviews](../2026-10-31-appendix-v14/README.md), [version 15 clarification](../2026-10-31-appendix-v15/README.md), and [version 16 notation revision](../2026-10-31-appendix-v16/README.md) remain separate records.
