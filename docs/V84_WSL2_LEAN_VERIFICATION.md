## Corollary 4.8

Let $S$ be any split restriction category whose total category $D$ is regular and finitely extensive, with a partial inverse in $S$ for each monomorphism in $D$. For $X\in D$ write $\Phi_X:\operatorname{Sub}_D(X)\simeq_o\operatorname{Idem}_S(X)$ for the domain order isomorphism. The new definition `RestrictionSubobjects.domainJoins` constructs
$$e\vee f=\Phi_X(\Phi_X^{-1}e\vee\Phi_X^{-1}f).$$
Monotonicity gives the two upper bounds. For $e,f\le g$, apply monotonicity of $\Phi_X^{-1}$, leastness of the subobject join, and then $\Phi_X$. The least domain is $\Phi_X(\bot)$. Thus `ComplementaryDomains` says that the meet is $\Phi_X(\bot)$ and the induced join is the identity. [Join, least domain and complementarity](https://github.com/flengyel/CategoricalEssentialIncompleteness/blob/b37f8908435a4c2991af5b95de4645980ac60a05/Lean/CategoricalEssentialIncompleteness/V46SignedFirstOrderIncompleteness.lean) · [Order isomorphism](https://github.com/flengyel/CategoricalEssentialIncompleteness/blob/b37f8908435a4c2991af5b95de4645980ac60a05/Lean/CategoricalEssentialIncompleteness/V46RestrictionSubobjects.lean#L124)

For a fixed variable object $V$, `F : NullaryPresentations V` supplies decidable variables, parameter-stable syntax including variable lists, and the initial derivation algebra for every $X$ and axiom subobject. Fix $X$, disjoint $a,b:\operatorname{Sub}_D(X)$, and consistency of their signed theory. In the namespace `SignedFirstOrder`, the checked declaration is

```lean
theorem essential_incomplete_iff_no_complementary_domains
    {S : Type u} [Category.{v} S] [RestrictionCategory S] [Splits S]
    [Regular (Tot S)] [FinitaryExtensive (Tot S)] (inverses : MonoInverses S)
    {V X : Tot S} (F : NullaryPresentations V) (a b : Subobject X) (hab : a ⊓ b = ⊥)
    (consistent : (F.presentation X).Consistent (theory F a b).val) :
    (F.presentation X).EssentiallyIncomplete (theory F a b) ↔
      ¬ ∃ p n : Idem X.obj, ComplementaryDomains inverses X p n ∧
        domain inverses a ≤ p ∧ domain inverses b ≤ n
```

The exported type requires only the stated hypotheses. A strict independent check expands the meet, join and two bounds. `complementaryDomains_iff` converts each domain separator into a complementary pair of subobjects and conversely. The subobject classification then supplies the Boolean-assignment and extension arguments. When restriction zeros and binary joins are available, `complementaryDomains_iff_complementary` identifies this order-theoretic test with the existing restriction-idempotent predicate. The specialization to $S=\operatorname{Split}(R)$ uses inherited restriction zeros. The transitive axioms for the join, the general theorem and this comparison are `Classical.choice`, `Quot.sound`, `propext`. [Exported theorem and native predicate comparison](https://github.com/flengyel/CategoricalEssentialIncompleteness/blob/b37f8908435a4c2991af5b95de4645980ac60a05/Lean/CategoricalEssentialIncompleteness/V46SignedFirstOrderIncompleteness.lean) · [Independent statements](https://github.com/flengyel/CategoricalEssentialIncompleteness/blob/b37f8908435a4c2991af5b95de4645980ac60a05/Lean/CategoricalEssentialIncompleteness/V46SignedFirstOrderIncompletenessChecks.lean) · [Correspondence](https://github.com/flengyel/CategoricalEssentialIncompleteness/blob/b37f8908435a4c2991af5b95de4645980ac60a05/FORMALIZATION_STATUS_V84.md#revised-passages-in-manuscript-order)
