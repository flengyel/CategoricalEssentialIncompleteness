3. FIRST IMPLEMENTATION BATCH: THE EXACT SECTION 3 RESULTS

Complete the following first. The labels, types, and hypotheses below have been checked against the v46 TeX; use the surrounding definitions as part of each statement.

| Manuscript statement | TeX label | Required content |
| --- | --- | --- |
| Theorem 3.1 | thm:comparison | Comparison for a lifted partial conditional and an arbitrary disjoint target pair |
| Corollary 3.2 | cor:separator | Nonexistence of a lifted complementary separator |
| Corollary 3.3 | cor:source-conditionals | Source inseparability from complementary source conditionals |
| Proposition 3.4 | prop:disjoint-joins | Construction of those total conditionals from disjoint morphism joins |

Theorem 3.1:

- R is a recursion category with ranges and binary restriction coproducts. A is a restriction category with ranges, restriction zeros, and binary restriction coproducts.
- F : R → A is a range functor: it preserves restrictions, ranges, restriction zeros, and binary restriction coproducts. Its canonical coproduct isomorphism is χ_{X,Y} : FX + FY ≅ F(X + Y). Product preservation is not an assumption.
- Fix a Turing morphism τ : U × U ⇀ U and an isomorphism b : U ≅ U + U.
- Set h = b τ Δ_U : U ⇀ U + U. On U + U put ε₀ = 1_U + 0_U and ε₁ = 0_U + 1_U, and define a_j = h*ε_j, restriction idempotents on U. Here f* denotes restriction inverse image, as defined in the manuscript.
- Let P and N be arbitrary disjoint restriction idempotents on FU, with F(a₀) ≤ P and F(a₁) ≤ N. They need not be complementary.
- Assume s : FU ⇀ FU + FU and ℓ : U ⇀ U + U, with s*(1_{FU} + 0_{FU}) = N, s*(0_{FU} + 1_{FU}) = P, and F(ℓ) = χ_{U,U} s. Both s and ℓ may be partial.
- Construct a total g : U → U with (Fg)*P = (Fg)*N = 0_{FU}.
- For this g, the further assumptions F(1_U) ≠ 0 and preservation of the join P ∨ N by inverse image along Fg imply P ∨ N ≠ 1_{FU}. Keep the zero-inverse-image conclusion independent of these further assumptions. A separate consequence for the same constructed witness is acceptable.

Use the source Turing construction and the equality h g = ℓ g. Applying F and the coproduct comparison gives the reversed inverse-image equalities. Monotonicity and disjointness then give zero inverse images. The final noncoverage conclusion uses totality, nontriviality, and preservation of the specified join. Do not assume global join preservation for the first conclusion.

Corollary 3.2 assumes F(1_U) ≠ 0 and binary-join preservation by total inverse images in A. Apply Theorem 3.1 to a complementary target pair to exclude the specified s and ℓ.

Corollary 3.3 retains those hypotheses and assumes that every complementary source pair c,c′ on U has a total ℓ_c : U → U + U with ℓ_c c = i₁ c and ℓ_c c′ = i₀ c′. Prove the reversed restriction inverse-image equations using the range agreement law. Set P = F(c), N = F(c′), and s_c = χ_{U,U}^{-1} F(ℓ_c); derive source inseparability from Corollary 3.2.

Proposition 3.4 is stated for a restriction category C with restriction zeros and binary restriction coproducts, assuming joins of parallel morphisms with disjoint restrictions. For complementary c,c′ on X, construct ℓ_c = (i₁ c) ∨ (i₀ c′) : X ⇀ X + X. Prove its two agreement equations and totality. It does not require a recursion category, a range functor, local connectedness, or weak choice.

The new Section 3 comparison results must not inherit the old target assumptions Splits, JoinInverse, LocallyConnected, or WeakChoice unless the precise manuscript statement independently requires the corresponding property. In particular, do not prove the first comparison only for complementary P,N, require ℓ to be total, or obtain it by specializing the old local-connectedness theorem.

Reuse candidates under Lean/CategoricalEssentialIncompleteness/:

- LocalLifting.lean: turing_diagonal, diagonal0, diagonal1. The turing_diagonal theorem already handles an arbitrary ℓ and gives the required total g. The old local_lifting and range_functor_lifting have stronger target hypotheses.
- RangeFunctor.lean: RangeFunctor, comparison, restriction/range preservation, map_total, map_sup, map_complementary, and the coproduct inverse-image identities. Inspect the exact fields and theorem types before reuse.
- RestrictionIdempotents.lean: order, inverse images, and domain incompleteness.
- DisjointJoins.lean: the construction from disjoint joins; check its hypotheses against Proposition 3.4.

The old namespace CategoricalEssentialIncompleteness.LocalConnectedness does not force a local-connectedness hypothesis on every declaration. Inspect elaborated signatures. Reuse appropriate lemmas without repository-wide renaming.

Translate composition explicitly: manuscript gf means g ∘ f, corresponding to Lean f ≫ g. In particular, h is diag U ≫ τ ≫ b.hom, and F(ℓ) = χ s becomes F.map ℓ = s ≫ χ.hom. Lean's category morphism type includes partial morphisms here; totality must be a separate proved property.
