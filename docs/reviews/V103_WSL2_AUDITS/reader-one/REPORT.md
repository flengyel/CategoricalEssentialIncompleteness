## The new preface

**Initiality and the Boolean converse.** The datum is a total assignment of sentences on the entire atom object `X`. The source positive and negative subobjects constrain it on two subobjects of `X`. An arbitrary assignment extends uniquely to a translation of presentations by syntax initiality. It gives a theory morphism exactly when both signed inequalities hold. The inverse laws of `SignedFirstOrder.homEquiv` give existence and uniqueness for these theory morphisms. Both naturality equations are proved. `unit_arrow` identifies the unit with the atom constructor. In the other direction the two complementary bounds define one Boolean assignment. The valid sentences form a consistent closed complete extension of the generated theory. A complete consistent extension yields a separator by pulling its theorem and refutation subobjects back along the atom constructor. The hypotheses include the initial proof algebras for each axiom subobject, and the chosen syntax and list algebras in parameter slices. The even and odd computation sets respectively map into the provable and the refutable codes of each consistent c.e. extension of PA. **Miller sequences.** For a name `p` of `a`, the set of coordinates whose first binary digit in `p` is zero contains the lower strict cut and misses the upper strict cut. The same digit-reading code works for all `p`, with a potentially different answer at coordinates equal to one half. A fixed set `S` between the two cuts with one decision index for all names of `a` would have two uniformly semidecidable complementary fibers in the category of `a`. Those fibers contradict the inseparability in Corollary 9.4. The existence of `a` with the fixed-index property is a further theorem. The proof uses a finite-coordinate fixed point and compactness to produce the simultaneous witness.
