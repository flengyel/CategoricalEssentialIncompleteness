## (C) Minor issues

**1. Appendix E.5, p. 100.** “Write $B=B_U$” precedes $e:EB\cong1_{\mathcal D}$. Here $E$ has domain $\mathcal D/U$. The earlier $B_U$ takes partial morphisms in $\mathscr C$ to partial morphisms in $\mathscr C[U]$. For example, at $U=1$ in sets and partial functions, $B_U$ carries the nowhere-defined endomorphism of a singleton to a partial morphism. That morphism is outside the domain of the displayed $E$. The proof in §5.3 and the Lean definition already use the restriction. Replace the abbreviation by “Let $B:\mathcal D\to\mathcal D/U$ be the restriction of $B_U$ to total morphisms.” This is a local typing error, repairable in the guide. Evidence is the domains of the two functors and the explicit restriction in the main proof. [Guide](../../../manuscript/latex/appendices/e-reading-lean-proofs.tex#L138) · [Definition of $B_U$](../../../manuscript/latex/sections/04-theory-extensions.tex#L235) · [Restriction used in the proof](../../../manuscript/latex/sections/04-theory-extensions.tex#L287) · [Formal instance](../../../Lean/CategoricalEssentialIncompleteness/V46AssociatedClosedTheories.lean#L34)

**2. Lemma 6.4, pp. 31–32.** The statement writes $D_{\ell(a_i)}(a_i)$ for a finite-valued primitive-recursive selector. The proof uses the graph $L$ of a chosen program and the entry condition $\bigvee_{j<s}(L(x,\bar j)\land D_j(x))$. These data matter in a nonstandard model. Assume PA is consistent and take $s=1$ and $D_0$ always true. A program that returns 1 if it finds a PA proof of $0=1$ of code at most $x$, and 0 otherwise, computes the zero function on the standard naturals. A model of $\mathrm{PA}+\neg\mathrm{Con}(\mathrm{PA})$ has an input on which that program returns 1. For the singleton list at that input, the displayed disjunction is false, whereas it is true if the constant-zero program is used. Both selected conditions have the asserted $\Sigma_1$ description. Their equivalence to each other in PA is not asserted or required. State the disjunction in the lemma, as it already appears in the proof. This is a local ambiguity about the selected formula. The model distinguishes the two readings, and the downstream constructor tests use explicit tags. [Lemma, its proof, and first application](../../../manuscript/latex/sections/05a-internal-syntax.tex#L291) · [Lean formula and PA theorem](../../../Lean/CategoricalEssentialIncompleteness/V46SelectorGraph.lean#L23) · [Second incompleteness theorem](https://plato.stanford.edu/entries/goedel-incompleteness/)
