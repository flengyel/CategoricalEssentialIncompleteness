## Appendix C numbering

For a domain D enumerable relative to K, the Turing parameter needs an ordinary total recursive function a such that $W^K_{a(z)}$ is the z-section of D. Here is a counterexample to deriving this from acceptability relative to K alone. Let I be the complement of a simple c.e. set. I is infinite, K-decidable and immune. Put the i-th standard oracle program at the i-th member of I and an empty-domain program at every other index. Both translations of numberings are K-computable. An ordinary total recursive parameter producing the distinct singleton domains {z} would have an infinite c.e. range contained in I, a contradiction. With finite oracle-machine codes, insertion of the parameter numeral is ordinary recursive. The proof already used this convention. Version 80 specifies it when introducing the numbering. The [ordinary compiler](../../Lean/CategoricalEssentialIncompleteness/OracleDomainNumbering.lean#L74) is used in [the Turing property](../../Lean/CategoricalEssentialIncompleteness/OracleRestrictedTuring.lean#L46).

## Exact comparisons still needed

* Lemma 6.4. Given the specified Σ₁ selector graph L, form the finite disjunction of L(x,j) and Dⱼ(x) conjoined branch by branch. Apply the finite-membership theorem to that formula. In every PA model, a list is accepted precisely when each entry has a witness to one of these branches. The [existing check](../../Lean/CategoricalEssentialIncompleteness/V46PrimitiveRecursiveTags.lean#L411) uses the interpretation of `codeFor hf`, selected from implementations of the externally specified function. Two implementations equal on the standard naturals need not agree in every PA model. An explicit application of finite membership to the supplied graph suffices. No PA-provable range bound on every standardly finite-valued implementation is required.
* §8.6. For the printed named formula, construct both signed pullbacks as disjoint c.e. sets, prove both diagonal inclusions, and show identity action and both functor laws on fixed-language theory inclusions. An isomorphism with a different implementation is optional. For the separate Bernardi claim, take a partial recursive function constant with values a and b on the disjoint c.e. diagonal sets A and B, respectively, and undefined elsewhere. A totalization modulo R pulls a separator of two distinct classes back to one separating A and B. For two disjoint nonempty unions choose one class in each.
