## Parameterization with an ordinary value program and an oracle domain

Fix the manuscript pairing $p:\mathbb N^2\to\mathbb N$. For the chosen finite oracle-machine numbering there is an ordinary total recursive function $s:\mathbb N^2\to\mathbb N$ such that
$$
\forall A\subseteq\mathbb N\ \forall e,z,x\in\mathbb N,\qquad
x\in W^A_{s(e,z)}\ \Longleftrightarrow\ p(z,x)\in W^A_e.
$$
For a fixed program computing $p$, the machine indexed by $s(e,z)$ first computes $p(z,x)$ on input $x$, then runs $e$ with oracle $A$ on that value. The operation on finite program descriptions is computable before $A$ is chosen. In particular, $z$ and $e$ are arguments of a function on natural numbers. [Revised proof, lines 97–126](https://github.com/flengyel/CategoricalEssentialIncompleteness/blob/986dee4d54d202a452009146cc29d19a544b0000/manuscript/latex/appendices/c-section-lifting.tex#L97-L126)

For a morphism $v:\mathbb N^2\rightharpoonup\mathbb N$, choose its ordinary partial recursive extension $v_0$ and a single oracle index $d$ for the coded domain $p[D_v]$ relative to $K$. Ordinary parameterization gives total recursive $t$ with $\varphi_{t(z)}(x)\simeq v_0(z,x)$. Put $r(z)=p(t(z),s(d,z))$. For each $z$, the domain of $x\mapsto\tau_K(r(z),x)$ is
$$
\operatorname{dom}(v_0(z,-))\cap W^K_{s(d,z)}
=\operatorname{dom}(v_0(z,-))\cap(D_v)_z=(D_v)_z .
$$
The last equality uses $D_v\subseteq\operatorname{dom}(v_0)$. On that domain the value is $v_0(z,x)=v(z,x)$. ## The two domain enumerations

In the Lean source let $L^A_a(x)$ abbreviate `oracleDomain A a x`. If $A{\upharpoonright}n$ is the list of the first $n$ characteristic-function values, this proposition says that for some $n$ the ordinary code at $a$ halts on the encoded pair $(x,A{\upharpoonright}n)$. The checked function `sectionIndex` is computable in its two arguments and satisfies the section law for every oracle, using `Nat.pair`. The checked Turing property pairs the two computable functions and proves equality of partial morphisms. [Finite prefixes](../../Lean/CategoricalEssentialIncompleteness/OracleFinitePrefixes.lean#L26) · [Section code and domain law](../../Lean/CategoricalEssentialIncompleteness/OracleDomainNumbering.lean#L60) · [Ordinary specialization](../../Lean/CategoricalEssentialIncompleteness/OracleProgramSpecialization.lean#L24) · [Turing property](../../Lean/CategoricalEssentialIncompleteness/OracleRestrictedTuring.lean#L47)

For the domain comparison at the two presentations, the following ordinary total recursive translations suffice.

1. Given a finite oracle-machine index $e$, let $u(e)$ index the ordinary program on $(x,w)$ that simulates $e(x)$ with the binary word $w$ as a finite table of oracle answers. If $e$ asks a question outside that table, the simulation diverges. It halts precisely when the simulation reaches a halt using only entries of $w$. A terminating oracle computation uses finitely many positions, so it is captured by a sufficiently long prefix. Conversely, a halting finite-prefix simulation with the true answers extends to the computation relative to $A$. Thus $L^A_{u(e)}(x)\leftrightarrow x\in W_e^A$ simultaneously for all $A,e,x$.
2. Given an ordinary code index $a$, let $v(a)$ index the oracle machine that obtains $A{\upharpoonright}n$ for successively larger $n$ and dovetails the ordinary code on each resulting $(x,A{\upharpoonright}n)$. It halts on the first observed halt. Thus $x\in W_{v(a)}^A\leftrightarrow L^A_a(x)$ simultaneously for all $A,a,x$. Both translations specialize a fixed simulator in the program index by ordinary parameterization.
3. If $p$ is chosen to be `Nat.pair`, $u(s(e,z))$ and `sectionIndex (u e) z` denote the same domain for every oracle. For a different $p$, precompose the program on the paired input with the total recursive change of encoding taking `Nat.pair z x` to $p(z,x)$. These conclusions are equivalences of membership predicates. No numerical equality between translated indices follows. The two translations concern the domain component. The ordinary extension used to compute values retains the separate witness $t$ of the preceding proof.

The required WSL2 comparison is the domain law for a specified presentation of the finite machines, or the application of a checked general representation theorem to that presentation and its pairing. For the literal diagonal sets in the counterexample, a translation of a domain index with its numerical input held fixed does not by itself identify the sets obtained by changing both an index and its self-input. For the finite-prefix presentation, the source proves the halting reduction directly: the first program ignores its input and returns zero when the original program halts on its own index. The second coordinate of the reduction is fixed at zero. Membership in the separating set tests the parity of the first program’s ordinary diagonal output. This test makes no reference to the oracle-domain program.
