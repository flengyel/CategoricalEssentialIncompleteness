## Literal realization and unique parsing

In `manuscript/latex/sections/05-syntactic-recursion-category.tex:8–36,148–173`, set $0=\varnothing$, $1=\{0\}$, $K(a,b)=\{\{a\},\{a,b\}\}$. Starting at the von Neumann ordinal $ω$, form $P(A,B)=\{K(a,b):a\in A,b\in B\}$ and $U(A,B)=P(A,\{0\})\cup P(B,\{1\})$. Write $r(Q)$ for the recursive realization of the formal term $Q$. Every generated set has three distinct members. Use $0,1,2$ for the base, inject three members of the left factor by pairing with a fixed member of the right factor for a product, and inject the left summand with tag 0 for a sum. Kuratowski pair injectivity applies also when either pair has coincident coordinates.

For any set of pairs $R$, put $p_1(R)=\{a:\exists b\ K(a,b)\in R\}$, $p_2(R)=\{b:\exists a\ K(a,b)\in R\}$, and $F_i(R)=\{a:K(a,i)\in R\}$. Each is a separation from $\bigcup\bigcup R$, which contains both coordinates of every pair in $R$. These tests distinguish the three possible root constructors.

| Equality of realizations | Consequence |
|---|---|
| Base versus product or sum | $0\in\omega$. Every element on the other side is a pair and has the member $\{a\}$, hence cannot be empty. |
| Product versus sum | $p_2(P(A,B))=B$ since $A$ is nonempty. In $p_2(U(C,D))=\{0,1\}$, both tags occur since $C,D$ are nonempty. Three distinct members of $B$ rule out equality. |
| Product versus product | Both factors are nonempty, so $p_1(P(A,B))=A$ and $p_2(P(A,B))=B$. Equality gives both coordinate equalities. |
| Sum versus sum | $F_0(U(A,B))=A$ and $F_1(U(A,B))=B$ by injectivity of $K$ and $0\ne1$, even if $A=B$ or the summands overlap. |

Induct on $Q$ with the claim quantified over every other term $R$. The two equal-constructor cases use the induction hypotheses on the ordered children. Thus $r(Q)=r(R)\Rightarrow Q=R$. Bijection alone would lose all distinctions since each carrier is countably infinite. The restrictions on the constructors matter: $P(A,\{0,1\})=U(A,A)$, and $P(A,\varnothing)=\varnothing$ hides its first factor. Neither a two-element nor an empty generated factor is possible here.

The range of $r$ is exactly the least family of sets containing $ω$ and closed under $P,U$, by closure in one direction and structural induction in the other. On an actual member set of that range, its unique parse supplies a unique *specified* chart $\gamma$. The base chart sends the von Neumann $n$ to $n$. Product decoding of $m$ uses $a=v_2(m+1)$, $b=((m+1)/2^a-1)/2$ followed by child decoding. Sum decoding uses parity and $\lfloor m/2\rfloor$. Bijectivity therefore holds recursively; primitive recursiveness is in these numerical presentations.

## Source, target, and the representative

Lines 60–63 and 126–146 define the source on formal terms with every hom-set the same quotient $H_T=\mathbb{N}/{\equiv_T}$ of numerical indices by one uniformly $T$-provable graph equivalence. At each pair of actual target sets use those same charts, indices, and provability relation. The map is $Q\mapsto r(Q)$, $[e]\mapsto[e]$ at the transported endpoints. It respects identities and composition because the identity class and the class of the same compiled composite agree. Every hom-map is bijective. The inverse sends a realized set to its unique parse and uses the same class at its inverse endpoints. This yields inverse functors in the ordinary set presentation, with no assertion of Lean definitional equality between the categories. The categorical conclusion needs no c.e. assumption. For arbitrary consistent extensions of PA the target cannot instead be obtained by interpreting each class as an ordinary partial function: for instance, assuming PA consistent, PA plus its formal inconsistency is consistent and proves that a search for a PA contradiction succeeds. The search program returning zero on success therefore has the same class as constant zero, although the former diverges on all standard inputs.
