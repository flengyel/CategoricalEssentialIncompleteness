# §8.6. Precompleteness of PA-provable graph equality

**Relation and quantifiers.** Write $G(e,x,y)$ for the graph of evaluation used in §6. For *standard* indices $i,j$, let $i\equiv_{\rm PA}j$ mean that PA proves the universal closure of $G(\bar i,x,y)\leftrightarrow G(\bar j,x,y)$. The claim in §8.6 is that for every partial recursive $f:\mathbb N\rightharpoonup\mathbb N$ there is an ordinary total recursive $h:\mathbb N\to\mathbb N$ such that $f(n)\downarrow=j$ implies $h(n)\equiv_{\rm PA}j$. It puts no condition on $h(n)$ when $f(n)$ diverges. Bernardi gives provable program equality as an example on p. 125, and proves inseparability of distinct classes in Proposition 2(b), p. 126. [Manuscript](../../../manuscript/latex/sections/08-essential-incompleteness-of-arithmetic.tex#L316-L327) · [Bernardi](https://doi.org/10.1090/S0002-9939-1986-0848889-9)

**Construction in the paper's graph coding.** Let $e$ index $f$ and let $p$ be the exponential pairing of §6. Use its PA-provably functional and injective graph to form the following $\Sigma_1$ formula on a paired input $b$ and an output $y$:
$$
H_e(b,y)\ \longleftrightarrow\ \exists n,x,j\,
 [b=p(n,x)\ \land\ G(\bar e,n,j)\ \land\ G(j,x,y)] .
$$
Here $G(j,x,y)$ has a **variable** program index. A pair of witnesses on the same $b$ gives the same $n,x$ by injectivity of $p$, the same $j$ by functionality of the first computation, and the same $y$ by functionality of the second. These deductions take place in PA. Apply the search theorem for functional $\Sigma_1$ graphs (Lemma 6.2) to obtain a fixed standard $d$ with $\mathrm{PA}\vdash\forall b,y\,[G(\bar d,b,y)\leftrightarrow H_e(b,y)]$. Set $h(n)=s(d,n)$ for the ordinary primitive recursive parameter function in Lemma 6.1.

For each $f(n)\downarrow=j$, its finite standard computation yields a PA proof of $G(\bar e,\bar n,\bar j)$. Functionality now gives, in PA, $\forall k\,[G(\bar e,\bar n,k)\leftrightarrow k=\bar j]$. Substitute $b=p(\bar n,x)$ in the proved equivalence for $d$, use the pairing equations, and apply the PA specialization equation at $d,\bar n$. The result is
$$
\mathrm{PA}\vdash\forall x,y\,
 [G(\overline{h(n)},x,y)\leftrightarrow G(\bar j,x,y)] .
$$
This proof requires no PA proof of totality for $f$. It uses the finite standard trace for the single pair $n,j$ and proves the result for **all** inputs $x,y$, including nonstandard inputs in every PA model. Equality of the two partial functions on standard inputs alone would be insufficient.

**Existing proofs and precise remaining application.** The standard adequacy theorem relates the actual evaluation to the arithmetic graph; positive $\Sigma_1$ numeral instances transfer to every PA model. `output_unique` accepts a free program-index variable. The existing pairing-injectivity proof and the use of completeness for functionality are in the same file. Instantiate `search_uniform_of_functional` with $H_e$, use `specialize_eval` at the fixed $d,n$, and apply `specialize_natCast` to identify the internal index with the numeral for $h(n)$. At each standard program index, `canonicalPartrecGraphFormula_eval_iff_eventualGraph` identifies the three-variable evaluation predicate with the fixed-index graph at arbitrary model inputs. The finite graph calculation then gives uniform provable equivalence by completeness, as in the composition comparison. **From an arbitrary precomplete relation to two inseparable classes.** Let $R$ be a precomplete equivalence relation and fix $a,b$ with $\neg(a\,R\,b)$. Consider the partial recursive function that runs the ordinary diagonal computation at $n$ and returns $a$ on an even output and $b$ on an odd output. A totalizer $g$ for this function modulo $R$ maps the even diagonal set into $[a]_R$ and the odd one into $[b]_R$. For any recursive separator $C$ of the two classes, $g^{-1}(C)$ would be a recursive separator of the even and odd diagonal sets. A total Boolean decision of the latter separation gives a contradiction: on input $n$ output 1 when it accepts $n$ and 0 otherwise, and evaluate the resulting program at its own index. If $U,V$ are disjoint nonempty unions of classes, choose $a\in U$, $b\in V$. A separator of $U,V$ would separate $[a]_R,[b]_R$. Neither argument assumes that the classes or their unions are computably enumerable.

Thus WSL2 can state the generic result for arbitrary predicates on $\mathbb N$, with separation by a recursive set. An object of the paper's $\operatorname{Pair}(\mathrm{Rec})$ requires c.e. supports; that extra requirement would restrict Bernardi's statement. An exact source formulation can take a precomplete relation and two elements from different classes as hypotheses and rule out each recursive separator directly. The preceding functor of §8.6 already derives its own inseparability from the diagonal inclusions.

For a concrete distinction between these domains of discourse, take $e\,R\,j$ to mean equality of the two ordinary partial recursive functions. This relation is precomplete: $g(n)$ is the index of the program on $x$ which first computes $f(n)$ and then evaluates the returned program at $x$. The class $E$ of the nowhere-defined function is not c.e. Indeed, uniformly in $n$, choose a program which returns zero on every input if the diagonal computation at $n$ halts and diverges on every input otherwise. Its index belongs to $E$ exactly when $n$ is outside the diagonal halting set. If $E$ were c.e., the halting set and its complement would both be c.e. Bernardi's theorem applies, for example, to $E$ and the class of the constant-zero function, even though these two supports do not define an object of $\operatorname{Pair}(\mathrm{Rec})$.
