## C. A proof valid in every model of PA

In v78, Lemma 6.4 took a primitive-recursive selector with graph $L(x,w)$ and replaced $w$ by $w\bmod s$. This can change the selected condition in a nonstandard model. Take $s=1$, take $D_0$ identically true, and choose the program that returns $1$ when its input codes a PA proof of $0=1$, and $0$ otherwise. If PA is consistent, every standard output is $0$. PA cannot prove that this program always returns $0$, since that would prove its consistency. Reduction modulo $1$ accepts every input, whereas testing the actual output for equality to $0$ can reject an input in a model of PA.

For a fixed presentation $L$, the condition needed at one entry is
$$
C_\ell(x)\;\equiv\;\bigvee_{j<s}\bigl(L(x,\bar j)\land D_j(x)\bigr).
$$
This is a finite disjunction of $\Sigma_1$ formulas. Applying the first part of the lemma to $C_\ell$ proves the finite-list assertion inside PA. The existing Lean theorem quantifies over $j:\mathrm{Fin}(s)$ and tests equality with the original program output.
