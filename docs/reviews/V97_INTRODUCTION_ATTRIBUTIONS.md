# Response to the review of manuscript v96

Manuscript v97 incorporates points 1–4 in §1 and the two source-link changes in point 5. Point 6 concerns a theorem stated for restriction idempotents.

1. **Smullyan.** Section 1 first defines strong separation by a predicate in a representation system. A predicate defines a set when it strongly separates that set from its complement. With the effective coding of §8, Theorem 22 excludes a recursive separator of the codes of provable and refutable sentences when every recursive set is definable. Consistency gives disjointness. Theorem 23(b) assumes consistency and a predicate strongly separating a recursively inseparable pair. See *Theory of Formal Systems*, Chapter III, pp. 48, 52, 59–60. [Revised opening](../../manuscript/latex/sections/01-introduction.tex#L3-L18)
2. **MPV and completeness.** Murwanashyaka, Pakhomov and Visser define the propositional-logic-like property in §4.1 and prove it for $\mathsf{Jan}$ in Theorem 4.3. It supplies a complete consistent extension for every choice of signs on the $A_n$. That extension contains the signed axioms for $B,C$ exactly when the chosen set contains $B$ and is disjoint from $C$. [MPV, §§4.1–4.2](https://research-portal.uu.nl/ws/files/240671111/exad005.pdf#page=6)
3. **Effectiveness.** Section 1 gives the deduction. If $D$ is recursive, one can enumerate the axioms of $\mathsf{Jan}_D$ and their consequences. An enumeration of those consequences decides membership in $D$ by waiting for $A_n$ or $\neg A_n$. Completeness ensures that one appears, consistency that only one does. [Related-work paragraph](../../manuscript/latex/sections/01-introduction.tex#L297-L311)
4. **Shoenfield.** For a given nonrecursive c.e. set $A$, Theorem 1 constructs the recursively inseparable c.e. sets $B,C$, each of the degree of $A$. Theorem 2 uses this pair in the signed theory. Shoenfield’s sentence $\Phi_n$ specifies a class of size $n$. MPV’s $A_n$ specifies a class of size $n+1$. [Shoenfield, pp. 389–391](https://doi.org/10.2307/2964013) · [§1](../../manuscript/latex/sections/01-introduction.tex#L290-L300)
5. **Appendix E.** The two references to the registered solution now open the v3 tag at commit `efda31344ec6420142468ab28af9d96deab571e7`. The v3 and v94 source tags have the same `Lean/CEIPalomar` tree, `f28557044f0b25de82bb6495d10de4a2714dcf38`. [Criterion and Boolean assignment](https://github.com/flengyel/CategoricalEssentialIncompleteness/blob/cei-v72-palomar-v3/Lean/CEIPalomar/Solution.lean#L83-L110) · [Arithmetic witness](https://github.com/flengyel/CategoricalEssentialIncompleteness/blob/cei-v72-palomar-v3/Lean/CEIPalomar/Solution.lean#L114-L145)

The manuscript calls these the theorem and refutation domains and treats their representations by subobjects in the split case. The Lean docstring follows this distinction.
