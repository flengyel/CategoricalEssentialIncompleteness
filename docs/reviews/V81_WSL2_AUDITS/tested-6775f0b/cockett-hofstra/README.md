## Mathematical verdict

1. **Finite-arity computability.** A total point codes a morphism into the first power. At zero inputs the point is applied to itself. At two or more inputs, the same code is total through the penultimate argument. Positive outputs are tested component by component. At positive input arity and zero output arity, the code tests each coordinate of the actual restriction endomorphism, even before assuming a partial combinatory algebra (PCA). At zero input and output arity the printed definition refers back to the scalar’s own domain. The implemented test requires the scalar to be the domain of a coded partial element. This inference follows from the intended computable restriction category and its computable total point. The original reconstruction gives the argument and a counterexample to accepting every ambient scalar. [Definitions and codes](../../../../../Lean/CategoricalEssentialIncompleteness/V46ApplicativeCodes.lean#L44) · [Coordinates and domains](../../../../../Lean/CategoricalEssentialIncompleteness/V46ApplicativePolynomials.lean#L45) · [Independent reconstruction](primary-reconstruction.md)

2. **Theorem 4.9(i).** In the category of computable morphisms on formal powers of a PCA, the given application is a Turing morphism. Its total parameter for a positive parameter arity is the corresponding prefix of one code. At zero parameter arity it is the code point. A total computable pairing and computable unpairings split the second power off the first. A total point and the terminal morphism give the zero-power retraction. Products and composition give the others. Hence the first power is a Turing object for every input and output power. [Parameters and Turing object](../../../../../Lean/CategoricalEssentialIncompleteness/V46ComputableTuringCategory.lean#L44) · [Finite-power retractions](../../../../../Lean/CategoricalEssentialIncompleteness/V46ComputablePowerRetractions.lean#L86)

3. **Preservation of finite restriction products.** Write $F$ for the inclusion of these powers into the ambient category and $P$ for the chosen product of two formal powers $X,Y$. For any ambient object $W$ and any two partial morphisms $f:W\to FX$ and $g:W\to FY$, there is a unique $h:W\to FP$ whose projections are $f\bar g$ and $g\bar f$, with $\bar h=\bar f\bar g$. In diagrammatic Lean notation the first projection is `rst g ≫ f`. I independently tested this unequal-domain form and derived an inverse to the canonical comparison $\langle F\pi_X,F\pi_Y\rangle:FP\to FX\times FY$. The inverse comes from the two total ambient projections. The empty formal power and each chosen terminal morphism map to their ambient counterparts. These tests allow every ambient source $W$. [Universal property](../../../../../Lean/CategoricalEssentialIncompleteness/V46ComputablePowerInclusion.lean#L114) · [Independent product proofs](AmbientProducts.lean)

4. **Theorem 4.9(ii).** For a Turing object with designated application, every ambient morphism between its finite powers is computable. This proves combinatory completeness. Take the ordinary idempotents on those powers that split in the ambient category. This class contains the identities. Splitting it recovers the ambient category up to equivalence. The retractions here range over every ambient object. The two functors of the chosen equivalence preserve restriction. For the realization functor, the proof uses the totality of the section in a splitting and restriction axiom R4. Preservation in the other direction follows by equivalence. [Splitting class and equivalence](../../../../../Lean/CategoricalEssentialIncompleteness/V46TuringComputablePowers.lean#L32) · [Restriction equations](../../../../../Lean/CategoricalEssentialIncompleteness/V46ComputablePowerRestriction.lean#L76) · [Independent proof](PCAObservations.lean)
