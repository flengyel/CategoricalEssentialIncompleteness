| Montagna, pp. 105–106 | The object sets are generated from the natural numbers by Cartesian products and disjoint sums tagged on the right by zero and one. The unprimed equality of programs has one PA proof for all inputs. The primed relation instead asks for a PA proof separately at each standard input. [Montagna, 1989](https://doi.org/10.1305/ndjfl/1093634998) |
| Montagna, p. 108 | The universal program evaluates a code at its input. Formalized parameterization gives its Turing property. The present realization equivalence takes each formal object to its generated set and preserves the represented program class. The pointwise-composition obstruction has its own formal proof.
