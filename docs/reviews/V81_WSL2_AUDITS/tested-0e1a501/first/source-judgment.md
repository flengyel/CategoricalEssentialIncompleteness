## Effective extensibility in §8.3

The first sentence fixes a presentation of a consistent theory and names Pour-El’s effective extensibility. The next sentence says that a recursive function sends an index for additional c.e. axioms to an independent sentence whenever the extension is consistent. My sealed reconstruction reads this as the property being studied. The unqualified second sentence also admits a claim that every fixed presentation of a consistent theory has such a function. The second reading fails already at an index for the empty additional axiom set. For example, the theory in the language of equality axiomatized by the assertion that all elements are equal has, under ordinary nonempty semantics, just the one-element model up to isomorphism. Completeness of first-order logic makes that consistent theory complete. It has no independent sentence. [Manuscript, §8.3, lines 4–9](../../../../../manuscript/latex/sections/08b-uniform-independent-sentences.tex#L4) · [Pour-El’s explanation, §3](https://pi.math.cornell.edu/~yytran/PourEl_recursion_axiomatizable_theories.pdf)

Theorem 8.6 explicitly fixes PA and its axiom presentation. Its existential quantifier for the internal morphism precedes all consistent extension indices. The proof establishes both failures of derivability at the value of this same morphism. No later result uses the stronger reading of the preceding prose. A local clarification would read “A presentation is effectively extensible if a recursive function sends each index for a c.e. set of additional axioms to an independent sentence whenever the extension is consistent.” [Theorem 8.6](../../../../../Lean/CategoricalEssentialIncompleteness/V46ArithmeticUniformIndependent.lean#L204) · [Reader’s applications](Independent.lean)
