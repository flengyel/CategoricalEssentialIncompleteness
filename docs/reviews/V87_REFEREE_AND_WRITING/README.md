## Primary sources

**Bernardi.** Section 2, p. 125, lists PA-provable equality of the partial recursive functions computed by program indices as an example of a precomplete equivalence relation. Proposition 2(b), p. 126, proves that two distinct classes are recursively inseparable, indeed effectively inseparable. A separator of two disjoint nonempty unions would separate one class from each. The manuscript expresses equality for its chosen coding by PA-provable equivalence of program graphs. [Original article](https://doi.org/10.1090/S0002-9939-1986-0848889-9) · [Author’s full text](https://www.researchgate.net/publication/303491669_Precomplete_equivalence_relations_in_dominical_categories) · [Lean proof](../../../Lean/CategoricalEssentialIncompleteness/V46ProvableProgramEquality.lean#L112)

**Miller.** Theorem 6.3 states that the real belongs to the range of the sequence. Lemma 6.2, the fixed-point proof and the paragraph after the theorem identify the coordinate with the program index. This is the step used when the reduction in §9 specializes a program to an index $h(e)$. Miller uses metric-space names. [Author’s text, pp. 12–13](https://people.math.wisc.edu/~jsmiller8/Papers/continuous.pdf#page=12)

**Bauer–Hanson.** In v3, §2.1, equation (2.2) and Definition 2.1 give binary names and a rational output within the strict error bound. One program must work on every name at every precision. Its output index may depend on both. Definition 2.1 permits real values in general, whereas the interval construction in the proof of Theorem 2.2 gives the singleton conclusion for $r\in[0,1]$. The restriction matters: an oracle-independent program naming 2 could never occupy its own coordinate in a sequence in the unit interval. Section 9 states the restricted formula. The interval at coordinate $d$ uses computations of program $d$ in the chosen numbering. Lean proves existence for that evaluator and its rational coding. [Definition 2.1, p. 7](https://arxiv.org/pdf/2404.01256v3#page=7) · [Theorem 2.2 and the interval construction, pp. 8–9](https://arxiv.org/pdf/2404.01256v3#page=8) · [Lean quantifiers](../../../Lean/CategoricalEssentialIncompleteness/V46MillerRealComputation.lean#L25) · [Lean existence theorem](../../../Lean/CategoricalEssentialIncompleteness/V46MillerFixedPoint.lean#L125)

**Pour-El.** The reference flagged against v85 had been checked for v86. Section 8.3 retains the note identifying the printed intersection in the conclusion of Definition 8 (p. 274) and the undecidable-sentence condition on p. 272. [Original paper, p. 272](https://pi.math.cornell.edu/~yytran/PourEl_recursion_axiomatizable_theories.pdf#page=7) · [p. 274](https://pi.math.cornell.edu/~yytran/PourEl_recursion_axiomatizable_theories.pdf#page=9)
