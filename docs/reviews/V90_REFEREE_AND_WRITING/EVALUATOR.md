# Universal object, frame and Turing morphism

I reconstructed Lemmas B.5–B.6, Theorem B.7, and the use of (33) in Proposition 10.1 from the manuscript at `153f1f398eec71e7d0ed34a86e280349e2c0071d`, then compared their hypotheses, types and equations with the Lean sources.

**Lemma B.5.** At the center the embedding records a code for the point and codes for both transition images. At endpoint $i$ it records the code for that endpoint point. Projecting the four-tuple to its first coordinate and the code for endpoint $i$ therefore gives the endpoint embedding after the transition. The inverse on the component images is computable and natural there. Lean proves totality and both partial-inverse equations for every coded fork. The restriction equivalence identifies this presentation with partial spans of numerical tuple diagrams. **Lemma B.6.** Coordinatewise unpairing commutes with each projection. In the coproduct, each component reads the parity of the same first coordinate. In the word isomorphism, that coordinate determines the length, so projecting before decoding gives the same word of endpoint pairs as projecting every decoded four-tuple. The three constructions have recursive inverses. The intermediate free-semigroup argument uses the nonempty-word fold, so it needs associativity and requires no unit. **Theorem B.7.** The central domain consists of the inputs on which three programs return values and the two endpoint values are the projections of the central value. Dovetailing and comparison enumerate this domain. The projected inputs then belong to both endpoint domains, and the same equalities give naturality there. Given a partial $F:Y\times V\rightharpoonup V$, each specialized program first waits for membership in its component domain. At a point of the central domain of $F$, subfunctoriality supplies endpoint membership and naturality of $F$ supplies both agreements. Conversely, if the specialized evaluator returns a value at the center, its central program has halted, so the input belongs to the central domain of $F$. This proves equality of partial morphisms. Lean gives the central graph with all three conjuncts, the total parameter with its three component formulas, and parameterization of every partial span of numerical tuple diagrams. **Equation (33) and §10.** At either endpoint the first coordinate $k$ of the parameter is ignored. For every pair $(\ell,x)$ the evaluator decodes the result of running program $p$ on the code of that pair. If the program diverges, the evaluator is undefined. For any c.e. parameter carrier $Z$ and partial $F:Z\times\mathbb N^2\rightharpoonup\mathbb N^2$, specialization therefore gives a total parameter of the form $(0,s(z))$ in §10 and the same partial map at both endpoints. Lean states both endpoint graph equivalences for arbitrary coordinates and both morphism equalities for this single parameter.
