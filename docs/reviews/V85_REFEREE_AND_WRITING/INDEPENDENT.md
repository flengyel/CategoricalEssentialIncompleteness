## The two corrections

**Lemma 6.4.** The displayed predicate fixes a binary graph formula and tests the finitely many allowed outputs. To stress the distinction between standard behavior and PA-provability, take a program returning the first out-of-range index whenever its input codes a PA proof of contradiction, and zero otherwise. Assuming PA is consistent, it returns zero on all standard inputs, while a model of PA plus the negation of its consistency sentence has an input where it returns the out-of-range index. At that input every displayed branch fails. The finite-witness proof still works. The actual producer takes an arbitrary binary Σ₁ formula, so no PA proof of the selector's range is needed.
