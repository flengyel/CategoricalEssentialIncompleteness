### Selector reconciliation and consequences

The finite-case expression is mathematically correct as written. In each PA model the displayed disjunction demands an actual valid tag. It can be applied to the program chosen by the formal implementation. If the paper requires a selector accepted on *every* internal input, external finite range of a primitive recursive function does not ensure PA-provable boundedness for a separately specified program computing it. Reducing its result modulo positive s gives one program realizing the standard function with an internal bound. It changes the interpretation of the original program on any internal input where that bound fails.

There is a separate issue even when both programs have PA-provably finite range. Take s=2, D₀ true and D₁ false. One reader always returns 0 and another returns the characteristic function of the primitive-recursive predicate “x is a PA proof of contradiction.” Both compute the same external function if PA is consistent, and PA proves that each program returns a bit. In a model of PA+¬Con(PA) their selected conditions differ on a nonstandard proof code. The type `Nat.Primrec f` is a proposition. The implementation cannot receive the two programs via two proof terms of this proposition and retain separate nonstandard meanings. The code-to-graph theorem V46PrimitiveRecursiveTags:216–218 retains intensional data when an actual `Code` is supplied. The selected-condition theorem at :411 does not accept it. The finite implication helper V46FiniteSigmaOne:181–207 is also distinct: it uses Π₁ tag tests and is vacuously satisfied when none hold. The stated disjunction fails in that case.

Thus the lemma's existential reading is witnessed by choosing the graph of the chosen program as L. At the reviewed revision the correspondence table's stronger identification with a previously specified selector graph is unsupported without specifying that choice or a PA-provable graph comparison. To formalize the full graph-parameter form directly, quantify over L, substitute each numeral into L, form the finite Σ₁ disjunction and apply V46FiniteSigmaOne:171. A totality or finite-range premise is unnecessary for *this guarded equivalence*. The finite parser and derivation applications have independently checked constructor, fold and validation theorems. The comparison issue does not disprove them.

Two further distinctions govern the inventory. The realized-set gap S 148–173 concerns the very choice of target objects. The final true-arithmetic conclusion D 183–198 has full and faithful comparison and explicit source representatives for all labels; only the assembly into an exact common-object isomorphism is not displayed. Neither gap undermines numerically coded standard semantic soundness in §7. In contrast, the unformalized DPM result genuinely adds a statement about the source that none of the target results implies.
