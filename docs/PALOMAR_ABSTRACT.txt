Let X index the nullary predicates of an internal first-order calculus in a regular category with disjoint, pullback-stable finite coproducts. Assume the parameter-stable syntax and initial derivation algebras of Theorem 4.7. For subobjects A and B of X, let T(A,B) be the theory generated by the atoms indexed by A and the negations of the atoms indexed by B.

A consistent theory is essentially incomplete if every consistent closed internal extension in the same language is incomplete. Suppose A and B are disjoint and T(A,B) is consistent. Then T(A,B) is essentially incomplete if and only if no complementary subobjects C and D of X satisfy A ≤ C and B ≤ D.

Each Boolean assignment to the atoms gives a closed, consistent, complete theory U. Whenever the assignment is true on A and false on B, U contains T(A,B). There is a calculus of this kind with an inseparable pair of subobjects A and B for which T(A,B) is essentially incomplete.
